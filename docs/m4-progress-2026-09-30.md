## Delivered behavior

The contribution ledger uses the evaluator's complete result and preserves canonical tree order. Each row names its tree, evaluated contribution and explanation status (pending, leaf reached or grouped). Baseline, running explained total, complete raw score, named output and sigmoid transformation have separate labels. Four rows per page limit text density, never evaluation. The persistent console stays available as the alternative to wrist UI. Small nonzero probabilities use scientific notation when two decimal places would round to zero.

Next/Previous tree preserves accepted progress and pause. Back at a root returns to the preceding tree; Back within a tree removes one decision and invalidates later tree routes and grouped contributions. Replay/Restart resets the entire tour to Tree 1 and the baseline. Tree selection in the forest remains non-destructive. No transition moves the tracked camera.

The four original synthetic profiles retain stable identities and readable values. Next profile previews a selection without replacing the active session; Follow profile accepts it. Selection retires old animation tokens and replaces the session. The chosen identity remains on the score display. A deliberate arbitrary branch changes the ensemble to manual mode, clears the authoritative profile output/grouping and uses only accepted route contributions. Restoring profile mode creates a fresh deterministic session.

Try a change makes an independent draft with a distinct identity and a visible relationship to the original. Decrease/Increase, category selection and Set explicit Missing alter only the draft. Apply validates and evaluates the entire model before replacing the accepted state, gives the evaluation a new identity and restarts at Tree 1 root. Invalid or incomplete edits preserve the previous accepted result. Cancel and closing the menu discard the draft without changing accepted routes. Restore original resets draft values; Apply accepts the restoration. Missing is deliberate; an unfinished field cannot be applied. No dependent feature is silently changed. Edited results are hypothetical model sensitivity, not a causal promise.

Manual consistency intersects numeric intervals, exact category sets/complements and present/missing requirements across all accepted decisions. It respects strict upper bounds, inclusive lower bounds, declared domains and integer feasibility. A contradiction identifies feature conditions and tree/node locations. Revise earlier choice returns to the earliest conflicting decision and clears later state; Continue free exploration keeps the choices and Route score. Unsupported constraints report Consistency not verified. A consistent partial route never becomes a profile probability.

Short tour explains the active tree and explicitly groups remaining trees after its leaf. Group count, aggregate contribution and every tree identity remain inspectable in the ledger. Detailed tour clears grouping and exposes each route. Both retain the same complete evaluation. Pause, Step and Play remain available; tree transitions are deliberate. There is no enforced 90-second pace.

The Larger ensemble menu option creates a clearly synthetic 24-tree example by repeating the bundled three trees eight times with baseline 0.5. Features recur across trees so contradictory manual choices can be demonstrated. It uses the same four fictional profiles, the same evaluator and seven reusable visible platforms. New visitor's independent expected total is `0.5 + 8 * (-4.1) = -32.3`; changing previous clicks to 5 yields `0.5 + 8 * (-3.2) = -25.1`. Original three-tree fixtures are unchanged.
