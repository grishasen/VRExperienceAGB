Branch: `codex/m5-forest-experience`. Unity Editor: 6000.6.3f1, Apple Silicon. The user reported that the preceding navigation works and requested implementing M5 in its own branch, with a combined headset check later. This report does not accept the new M5 controls on Quest.

## Delivered behavior

The garden preserves the existing 50-tree startup demo, M3 list, A-button tree menu, manual routes and synthetic prepared-profile implementation. The left controller stick now walks relative to the horizontal viewing direction at up to 1.35 m/s. A radial 0.2 dead zone, bounded garden floor and a capped update interval prevent drift and large catch-up jumps. Right-stick snap turning and optional path-marker teleports remain. Walking is disabled in the case menu, tree list, tabletop view and help overlay. Only the observer origin moves; tracked head/controller local poses and model/session state are untouched. Continuous-movement comfort still needs a headset check.

Each pine has a separate transparent crown target that faces the observer from different approaches. Its read-only hover card also faces the observer and stays beside the crown; fixed planter names keep their original orientation. Pointing shows the existing structural/contribution information; pressing the trigger enters that tree directly. Fixed planter names remain small, retain their existing orientation and provide an additional selection target. The crown no longer depends on clicking the planter caption.

The optional **Tabletop view** shares the accepted ensemble. Its smaller pines retain canonical tree numbers, structural dimensions, signed contribution rings and selection feedback. Controls select any shown tree, enter it, change scale within 0.7–1.4×, rotate in 30-degree increments, reset the view, or return to the walkable garden. Stepped rows keep rear selection labels visible. Larger models use explicit 50-tree presentation pages with previous/next page controls and a displayed range; every model tree remains accessible and participates in evaluation. The original 50-tree demo fits on one page.

Entering and returning retains the selected tree, accepted decisions, reached-leaf contribution, profile identity, complete evaluation, explicit pause, tabletop scale/rotation and saved garden position. A return during an unfinished movement cancels the unaccepted transition according to the existing session policy. Returning is distinct from restarting. Opening help preserves the pending movement and prior pause; closing it resumes only when the prior state allowed it.

Tree presentation retains the seven-platform budget. Non-terminal boundary nodes show **Open subtree · N hidden** with exact descendant counts outside the current neighborhood. Selecting a summary opens that node's neighborhood without choosing a branch or adding a contribution. **Parent view** restores the preceding view; **Your current decision** returns to the accepted route. A separate context panel distinguishes inspection from route progress. While inspecting, branch controls and automatic advancement are suspended; current-route geometry and the sample are shown only when the current node is visible. Stable tree/node identities still bind labels and full-name hover.

The four-page **Help / legend** explains pointing, joystick/teleport movement, manual versus prepared-profile meaning, structure and signed-ring encodings, scale controls and recovery. It is available from the case menu, list, garden, tabletop view and tree menu; users can skip, close and reopen it. The existing seated/standing, Back, Restart and Return controls remain. The tree menu adds an explicit Pause/Resume control that preserves its chosen state when the menu closes.

The existing twilight environment and distant scenery are retained. M5 adds a quiet positional procedural breeze and a short selection cue, plus a sound toggle. No new light, downloaded asset, dependency, model or profile is introduced. The [asset register](asset-register.md) distinguishes project geometry, generated textures, original audio, fonts and SDK content; final distribution review remains part of M6.
